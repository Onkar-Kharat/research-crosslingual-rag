## 3. Detailed Textual Action Plan Across Sections

### 3.1 Abstract & Introduction (`sections/abstract.tex`, `sections/introduction.tex`)
- **Action:** Open directly with the core problem: cross-lingual evidence representation in fact verification.
- **Guardrail:** Disclose dataset ($N=163$ test, $N=103$ dev), language pair (Hindi–English), zero gold \textsc{Supported} instances, and the non-significant permutation test ($p=0.1180$).
- **Tone:** Replace marketing language with sober scientific terminology ("exploratory observational sensitivity", "diagnostic error stratification", "negative finding on surface risk calibration").

### 3.2 Methodology & Formulation (`sections/task_and_formulation.tex`, `sections/methodology.tex`)
- **Action:** Define the 3-class NLI mapping ($\mathcal{Y} = \{\text{Supported, Contradicted, Neutral}\}$).
- **Formulation:** Explicitly define the four paired conditions: $\hat{y}_{\text{nc}}, \hat{y}_{\text{dm}}, \hat{y}_{\text{ac}}, \hat{y}_{\text{sc}}$.
- **Transparency:** Disclose that development threshold tuning ($\tau^*=0.650$) failed to beat the zero-check baseline utility on dev data prior to test evaluation.

### 3.3 Experimental Setup & Results (`sections/experimental_setup.tex`, `sections/results.tex`)
- **Action:** Formulate the mathematical impact of $TP_{\text{sup}} \equiv 0$ on Macro-F1.
- **Reporting:** Present Table 3 with Wilson score 95% confidence intervals, both 3-class and 2-class Macro-F1, and exact CPU latencies.
- **Statistical Analysis:** Report both McNemar and permutation test p-values side-by-side in Table 4, with Benjamini-Hochberg FDR adjustments and clear metric divergence explanations.

### 3.4 Discussion & Limitations (`sections/discussion.tex`, `sections/limitations.tex`)
- **Action:** Structure discussion into:
  1. *Direct Empirical Observations* (flip rates, consensus contamination).
  2. *Consistent Interpretations* (why direct multilingual NLI preserves entity context).
  3. *Untested Hypotheses* (specific syntactic or phonetic failure modes).
- **Ten Explicit Limitations:** Document single language pair, sample size, extreme class skew, exploratory computational status, single verifier backbone, single MT engine, pre-retrieved snippet grounding, pending bilingual human validation, observational vs causal attribution, and heuristic risk gating scope.
