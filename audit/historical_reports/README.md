# Historical Audit Reports and Checkpoints

This directory archives historical audit reports, defect ledgers, decision checkpoints, and exploratory draft reviews generated during earlier phases of the research project.

## Archived Documentation
- `BLOCKER_LEDGER.csv`: Historical blocker ledger tracking defect triage.
- `DECISION_LOG.md`: Decision gate decisions and resolutions across project iterations.
- `EXPERIMENT_LINEAGE.md`: Early data provenance notes.
- `FREEZE_AUDIT.md`: Pre-freeze audit verification report.
- `FREEZE_GATE_REPORT.md`: Gate A/B/C verification checklist.
- `INDEPENDENT_REVIEW_FREEZE_CANDIDATE_V2.md`: Phase review notes from v2 candidate.
- `MANUSCRIPT_REVIEW_AND_TACL_READINESS.md`: Early assessment of TACL readiness.
- `README_RESEARCH_FREEZE.md`: Freeze handoff notes from candidate releases.
- `README_RESEARCH_REPAIR.md`: Historical repair plan from Phase 0.
- `RESEARCH_STATUS.md`: Pre-freeze status declaration.
- `REVIEW_ME_FIRST.md`: Previous reviewer quick-start guide.
- `STATUS.md`: Legacy project status record.
- `TACL_READINESS_ASSESSMENT.md`: Checkpoint analysis for TACL criteria.
- `V3_FREEZE_READINESS_REVIEW.md`: v3 candidate evaluation.
- `V3_NEXT_ACTIONS_CHECKLIST.md`: v3 remediation checklist.
- `reports/`: Early exploratory readout and literature audit drafts.
- `research/`: Early template documents.

All active, verified research documentation and authoritative manuscript files are maintained in:
- `docs/research/`: Research scope, 10-point limitations, provenance, and novelty assessment.
- `docs/manuscript/`: Complete TACL LaTeX manuscript, tables, figures, fact-check, and audit reports.
- `results/canonical/`: Frozen canonical per-instance predictions and statistical outputs.
