# Decision Gates

A — Literature: closest papers reviewed; exact combination compared; no novelty claim based only on keyword search.
B — Data: schema, evidence, language, license and annotation feasibility confirmed.
C — Pilot run: virtual environment, resource estimates, free-only compliance and smoke test checked.
D — Pilot: report denominators, label flips, error categories, annotation uncertainty, baselines and resource use; user approval before scale-up.
E — Full study: freeze RQs, primary metric, models, splits, thresholds and statistical plan.
F — Manuscript: every factual claim tied to verified source or real output; no fabricated results.
G — Submission: verify scope, fees, license, ethics and format. Explicit user approval required before submission.
