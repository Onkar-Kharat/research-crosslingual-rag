# Annotation Analysis Output Directory

This directory stores analytical outputs produced by `annotation_tool/scripts/analyze_agreement.py`.

### Current Status: AWAITING REAL SUBMISSIONS

Outputs generated here upon arrival of authentic submissions:
1. `aligned_two_annotator_evaluations.csv`: Aligned judgments matched across opaque IDs via the secret key.
2. `disagreement_queue_for_adjudication.csv`: Cases where Annotator 1 and Annotator 2 disagreed, queued for third-party expert adjudication.
3. `stratum_breakdown_summary.csv`: Stratum-specific counts and percentages.
4. `HUMAN_ANNOTATION_AGREEMENT_REPORT.md`: Comprehensive inter-rater agreement report with raw percentage agreement and Cohen's kappa.
